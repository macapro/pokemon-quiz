# 포켓몬 초성 퀴즈

일반 포켓몬과 메가진화 포켓몬이 함께 출제되는 반응형 웹 퀴즈입니다.

## 기능
- 개인 플레이: 문제 풀이, 힌트, 2분 제한, 정답 후 5초 뒤 자동 출제, 브라우저에 점수/최고 기록 저장
- 실시간 멀티플레이: 방 생성/참가 코드, 숫자 비밀번호(4~8자리), 방장 비밀번호 변경, 실시간 문제/정답/점수/순위, 2분 제한과 자동 다음 문제
- 힌트: 타입, 세대/지방, 첫·끝 글자, 도감 설명
- 기본 정답 점수 14점, 힌트 1회당 2점 차감
- 모바일/PC 반응형 화면


## 방장 및 방 초기화 업데이트
- 방 생성자는 자동으로 방장(👑)이 됩니다.
- 방장은 게임방을 나가면 해당 방의 참가자 연결, 방 데이터, 비밀번호가 삭제됩니다.
- 일반 참가자가 나가면 해당 참가자만 목록에서 제거되고 방은 유지됩니다.
- 방장이 연결을 끊으면 방도 종료됩니다.
- 연결된 참가자가 없는 오래된 방 기록은 같은 방 코드로 새 방을 만들 때 자동 정리됩니다.

## 방 코드와 비밀번호 통합
방 생성 시 입력한 숫자 방 코드가 비밀번호로도 사용됩니다. 참가자는 방 코드 하나만 입력하면 됩니다.
